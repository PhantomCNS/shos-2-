# shos-2-
Smart Home Operating System with Wi-Fi connection and phone interface  using ESP32

### Description
shos-2- is a Smart Home Operating System designed to run on the ESP32 microcontroller. It provides Wi-Fi connectivity and a user-friendly phone interface for controlling various smart home devices. The system is modular, allowing for easy integration of different sensors and actuators.

### Features

- Wi-Fi connectivity for remote access and control.
- Phone interface for user-friendly control of smart home devices.
- Modular design for easy integration of various sensors and actuators.
- Works with a variety of smart home devices, including lights, thermostats, and security systems.
- Can be extended with additional features and functionalities as needed.
- Can be used either offline or online, depending on the user's preference and requirements.
- Has an early alert system for gas detection using MQ-2 sensor and other environmental sensors.
