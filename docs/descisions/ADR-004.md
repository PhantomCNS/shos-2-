# ADR-004: Reading the Analog input of the MQ-2 

## Context

The MQ-2 gas sensor provides an analog output that varies with the concentration of gas in the environment. To utilize this sensor effectively, we need to read its analog input and convert it to a meaningful value.

## Decision

We will read the analog input from the MQ-2 sensor using the microcontroller's ADC (Analog-to-Digital Converter). The raw ADC value will be converted to a voltage level, which can then be used to determine the gas concentration based on the sensor's characteristics.

## Consequences

- The system will be able to monitor gas levels in real-time.
- Requires calibration of the sensor to ensure accurate readings.
- The ADC reading may be affected by noise, so filtering techniques may be necessary to obtain stable readings.

## Implementation
1. Connect the MQ-2 sensor's analog output to an available ADC pin on the microcontroller. in our case, we will use pin GPIO34.
2. In the firmware, configure the ADC to read from the specified pin (GPIO34).
3. Implement a function to read the ADC value and convert it to a voltage level.
4. Use the voltage level to determine the gas concentration based on the MQ-2 sensor's datasheet and calibration data.
