# ADR-003: Virtual switch to mute Buzzer from Blynk

------
## Context

We use a buzzer on the device for audible alerts. We want the user to be able to mute/unmute the buzzer remotely via the Blynk app without changing device firmware or hardware each time.
------
## Decision

Expose a Blynk virtual pin (e.g. V1) as a mute/unmute toggle. When the virtual pin is ON the device will suppress buzzer output; when OFF buzzer behaves normally. The state is persisted in device non-volatile storage so it survives reboots.
------
## Consequences

- Adds a remote control channel for audible alerts.
- Requires handling the virtual-pin command in firmware and using non-volatile storage (EEPROM, SPIFFS, LittleFS, or similar).
- If Blynk is unavailable the device retains the last mute state.
------
## Implementation

1. Assign a virtual pin in Blynk (suggested: V1) and add a Switch widget bound to that pin.
2. In firmware subscribe to VirtualWrite for V1 and update a boolean mute flag.
3. Persist the mute flag to non-volatile storage whenever it changes.
4. When attempting to drive the buzzer, check the mute flag and skip output if muted.

------
## Status
Accepted

------
### Notes
- Provide a physical override (local button or long-press) if desired so local users can unmute without Blynk.
- Document the virtual pin (V1) in the project README and Blynk project template.
